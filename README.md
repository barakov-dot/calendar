# Платёжный календарь бухгалтерской компании

Налоговые сроки, зарплата и свои напоминания по компаниям клиентов; уведомления в Telegram.
Один интерфейс для сайта и Telegram Mini App.

- План и состояние работ: [PLAN.md](PLAN.md)
- Правила разработки: [CLAUDE.md](CLAUDE.md)
- Запуск на сервере, копии, мониторинг: [deploy/DEPLOY.md](deploy/DEPLOY.md)

## Разработка (только Docker)
```bash
cp .env.example .env
```
```bash
make dev
```

Сайт — http://localhost:5173. В `.env` для входа нужны `JWT_SECRET` и, для бота,
`BOT_TOKEN`. Тестовые пользователи и компании — `make seed-dev` (при запущенном стеке).

Проверки перед изменениями на сервере:
```bash
make test
```
```bash
make lint
```
```bash
make check-amd64
```

`make help` показывает все команды.

## Ежегодная процедура (ноябрь–декабрь)

Без этого с января задачи следующего года **не создаются**.

1. **Производственный календарь.** Когда опубликовано постановление о переносе выходных,
   создайте `data/calendar/<год>.json` по образцу прошлого года: будни, ставшие выходными
   (`days_off`), и рабочие субботы или воскресенья (`working_weekends`). Сверьте число
   рабочих дней по месяцам с официальным календарём и добавьте эти числа в
   `backend/tests/test_calendar.py`. Загрузите:
   ```bash
   make calendar year=2028
   ```
   На сервере — тот же файл через «Настройки» → «Производственный календарь».
2. **Налоговые правила.** Скопируйте `rules/<прошлый год>.yaml` в `rules/<год>.yaml`,
   поменяйте `year` и `checked`.
3. **Изменения закона.** Пройдите каждое правило по статье из `source`: изменения НК РФ,
   законов № 17-ФЗ, 27-ФЗ, 125-ФЗ, 402-ФЗ, ТК РФ. Не меняйте срок без ссылки на норму.
   Неясное записывайте в `rules/questions-<год>.yaml`.
4. **Тесты.** Добавьте в `backend/tests/test_rules_golden.py` проверенные даты нового года.
   ```bash
   make test
   ```
5. **Сверка.** Выгрузите календарь тестовых компаний и отдайте бухгалтеру:
   ```bash
   make export year=2028
   ```
6. **Сервер.** `make backup`, затем `git pull && make prod`. Задачи пересчитаются сами.

На 2027 год остаётся проверить закон о взносах на травматизм — см.
[rules/questions-2026.yaml](rules/questions-2026.yaml).
